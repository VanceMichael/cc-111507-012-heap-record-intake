# 离线运维转储检索来源格式

支持 HPROF JAVA PROFILE 1.0.2、4或8字节标识，顶层 UTF8、LOAD_CLASS、HEAP_DUMP、HEAP_DUMP_SEGMENT、HEAP_DUMP_END；堆子记录 CLASS_DUMP、INSTANCE_DUMP、OBJECT_ARRAY_DUMP、PRIMITIVE_ARRAY_DUMP 及标准 ROOT 跳过。字段类型宽度采用 HPROF 定义，大端编码；类字段先当前类再父类，引用0为空。实例可以早于类定义。每个对象保留 objectId、classId、sourceOffset/length，数组保存元素类型/长度及可定位区间，未决引用不伪造对象。

`fixtures/scenarios.json` 给出本机来源入口和允许读取的资源；`GET /manifest` 返回同样的来源描述。`GET /trace` 返回当前进程内真实来源访问记录。资源接口为 `GET /files/百分号编码的资源名`，支持单段 Range、ETag 和 If-Match；资源名必须出现在来源清单中。数据不是新闻原文，不连接真实客户或设备。

格式参考：https://github.com/openjdk/jdk/blob/master/src/hotspot/share/services/heapDumper.cpp。本项目只承诺上文列出的范围；未列出扩展应保留原文并明确不支持，不能假装完整解析。
